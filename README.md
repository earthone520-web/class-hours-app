# 课时统计助手

一个适合手机操作的离线网页应用，用于课后即时打卡、月底统计课时、导出 Excel 可打开的 CSV。

## 功能

- 当日打卡：选择日期后，只显示当天有课的学员
- 出勤与未出勤记录，未出勤可填写原因
- 学员详情：点击头像或名字查看当月日历，出勤标绿，缺勤标红并显示原因
- 学员和班级可手动新增、编辑、删除
- 班级可直接排布具体上课日期，不需要填写时间段
- 班级人数自动跟随学员变动更新
- 月度统计与 CSV 导出
- 全量 JSON 备份导入导出
- 批量 CSV 导入学员
- 本地离线存储，不依赖后端
